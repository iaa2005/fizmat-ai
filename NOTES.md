# PII-Tracer локально

Проба модели [perplexity-ai/PII-Tracer](https://huggingface.co/perplexity-ai/PII-Tracer)
(MIT, 0,6B) на CPU — как прослойки, скрывающей личные данные до отправки в Fizmat.

- `model/` — веса и код модели с Hugging Face (1,2 ГБ, bf16), код прочитан.
- `.venv/` — torch 2.15 CPU, transformers 5.22 (модели нужен ≥ 5.2).
- `run.py` — русские примеры (всё выдумано): что нашла, что пропустила, время.
- `bench.py` — скорость: bf16/fp32, целиком/окнами.

    .venv/Scripts/python run.py

## Итоги 09.11.2026 (Ryzen 7 7840HS, 8 потоков)

- Нашла 18 из 18: ФИО, почты, телефоны в трёх записях, паспорт, дату выдачи,
  СНИЛС, ИНН, карту, адрес, пароль и ключ в коде, все повторы в разговоре
  (и «Игорь Валентинович», и одно «Игорь»).
- Лишнее: буква «й» в «Эйлера» (артефакт токенов — отсекать полосы короче 2 символов),
  `db.internal` как URL (спорно). Ньютон, Пушкин, формулы, даты-числа — не тронуты.
- СНИЛС и ИНН подряд склеила в одну полосу вместе со словами «СНИЛС», «ИНН».
- Чувствительность (здоровье) на русском почти не срабатывает: 0,08 на тексте про диабет.
- Скорость: сообщение 100–400 символов — 0,1–0,3 с. Разговор 4700 токенов — 16–21 с,
  и целиком модель видит только первые 4096 токенов. bf16 на этом CPU быстрее fp32.
  Значит, в прослойке проверять новое сообщение с коротким хвостом истории, а уже
  найденные значения скрывать во всей истории простой заменой строк.

## Прослойка `guard/` (09.11.2026)

Сервис на 127.0.0.1:47821, который оболочка (Tauri или Electron) держит рядом с окном fizmat.ai.

- `rules.py` — СНИЛС, ИНН, карта (контрольные суммы), паспорт, почта, телефон; темы
  (здоровье, вера, политика, интим, деньги, суд) по основам слов с начала слова.
- `detector.py` — модель + правила: правило режет склеенную полосу модели, проверка формы
  («по номеру» телефоном не бывает), отрезка «Я» перед именем, уже скрытое — везде.
- `vault.py` — одна таблица «значение ↔ [ИМЯ_1]» на человека в `%APPDATA%/FizmatGuard/vault/all.json`;
  телефон в любой записи — одна метка.
- `server.py` — `/scan`, `/mask` (с `keep`), `/restore`; только с fizmat.ai и с ключом
  из `%APPDATA%/FizmatGuard/token`, иначе 403.
- `inject.js` — вставляется в страницу: перехватывает `POST /c/{id}/messages|queue` и форму
  первого вопроса, показывает окно «что скроем», меняет метки в ленте обратно.
- `check.py` — проверка без сервера; `demo/` — тестовая страница вместо fizmat.ai.

    cd guard && ../.venv/Scripts/python server.py

Проверено в браузере на `demo/`: до сайта ушло `Меня зовут [ИМЯ_1], телефон [ТЕЛЕФОН_1],
СНИЛС [СНИЛС_1]. У меня [ДАННЫЕ_1].`, ответ с метками показан с настоящими значениями.

Не сделано: правка уже отправленного сообщения, файлы (docx/pdf), копирование ответа
(в буфер уходят метки).

## Оболочка `shell/` (Tauri 2)

`fizmat-guard.exe` (12 МБ): окно с https://fizmat.ai/home, при запуске поднимает
`guard/server.py` из `.venv` без консоли, при закрытии гасит. Скрипт `guard/inject.js`
вшит в программу и вставляется в каждую страницу.

- Страница зовёт команду Tauri `guard` (`/health`, `/scan`, `/mask`, `/restore`),
  программа передаёт запрос сервису с ключом — сама страница ключа не видит.
  Команда разрешена только страницам fizmat.ai (`capabilities/remote.json` + `allow-guard`).
- Папку `guard/` ищет в `FIZMAT_GUARD_DIR`, над `.exe` или в исходниках.
- Лог сервиса — `%APPDATA%/FizmatGuard/guard.log`.

    cd shell && npm install && npx tauri build --no-bundle
    src-tauri/target/release/fizmat-guard.exe

Проверка окна: запустить с `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9333`
и `node cdp.mjs "выражение"` (порт отладки — только для проверки, потом без него).

Нужны Rust (rustup, stable-msvc) и Visual Studio 2022 Build Tools с C++ (поставлены 09.11.2026).
Пока не переносимо: сервис берёт Python и модель из этой папки. Для раздачи — упаковать
сервис (PyInstaller или ONNX в самой программе) и собрать установщик NSIS.

Предел защиты: значения возвращаются в страницу fizmat.ai, и её код их видит. Прослойка
не даёт им уйти на сервер и в модели при обычной работе, но не защищает от взломанного сайта.
